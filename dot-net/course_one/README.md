# First Course Tasks

1. Create a .NET project in Visual Studio (Community Edition) and familiarize yourself with files such as `Program.cs`, `appsettings.json`, and controllers.

2. Understand the HTTP protocol and create a simple Web API that displays static data.

3. Learn about CRUD operations:

| Operation | HTTP Method | Description          |
| --------- | ----------- | -------------------- |
| Create    | POST        | Add new data         |
| Read      | GET         | Retrieve data        |
| Update    | PUT         | Modify existing data |
| Delete    | DELETE      | Remove data          |

4. Use Postman to test the API and experiment with read, add, and delete operations.

5. Learn about the Audit Log concept and create an additional database table to store changes.
